# 📖 Fav-Book

A **simple and clean Django web application** for storing and managing your favorite books.
This project demonstrates CRUD operations, Django models, templates, and clean backend structure.

---

## 🚀 Project Overview

**Fav-Book** allows users to:

* Add their favorite books
* View all saved books
* Update book information
* Delete books from the list

It’s a great example of a **beginner-friendly Django CRUD project**.

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/mohammadbjoma/fav-book.git
cd fav-book
```

### 2️⃣ Create virtual environment

```bash
python -m venv venv
source venv/bin/activate      # macOS/Linux
venv\Scripts\activate         # Windows
```

### 3️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Apply migrations

```bash
python manage.py migrate
```

### 5️⃣ Run the server

```bash
python manage.py runserver
```

📍 Open in browser:

```
http://127.0.0.1:8000/
```
